# E-Waste Platform

The E-Waste Platform is a web application that helps users understand and predict electronic-waste generation. It combines an interactive dashboard, an e-waste prediction tool, and a traceability page in one simple interface.

## What the platform does

- Shows awareness information and charts about electronic-waste disposal methods.
- Displays average annual e-waste by household income group.
- Predicts annual e-waste generation in kilograms from household and recycling-related information.
- Provides a traceability page for following e-waste information.

## Run the application

### Requirements

- Python 3
- The files included in this repository:
  - `ewaste_platform/dataset/e-waste_final.csv`
  - `ewaste_platform/models/ewaste_predictor.joblib`

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Harry121199/e-waste_platform.git
   cd e-waste_platform
   ```

2. Create and activate a virtual environment:

   ```bash
   python -m venv .venv
   ```

   On Windows:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

   On macOS or Linux:

   ```bash
   source .venv/bin/activate
   ```

3. Install the required packages:

   ```bash
   pip install -r ewaste_platform/requirements.txt
   ```

4. Start the application:

   ```bash
   cd ewaste_platform
   python app.py
   ```

5. Open the local address shown by Flask in your web browser.

## Pages

- `/` — Main page with e-waste awareness charts.
- `/predict` — Prediction form. It supports viewing the form with `GET` and submitting information with `POST`.
- `/traceability` — Traceability page.

## Making a prediction

The prediction form uses the following information:

- State
- Locality type
- Household size
- Income bracket
- E-literacy level
- Total devices owned
- Average device age in years
- Broken devices stored
- Upgrade tendency
- Disposal method
- Recycling awareness

The application returns the estimated annual e-waste in kilograms. The prediction is generated by a saved Random Forest regression pipeline trained from the included dataset.

## Model and data

The training script in `ewaste_platform/model.py`:

1. Loads `dataset/e-waste_final.csv`.
2. Uses household, device, awareness, and disposal information as input features.
3. One-hot encodes categorical values and passes other values through unchanged.
4. Trains a Random Forest regression model with 100 estimators.
5. Saves the trained pipeline as `models/ewaste_predictor.joblib`.

The application loads this saved model and the dataset when it starts. Keep the dataset and model in their existing folders so the application can find them.
